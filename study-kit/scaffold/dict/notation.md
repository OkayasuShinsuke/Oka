# 記法の取り決め

template/preamble.tex のマクロと必ず一致させる。変えるときは両方を同時に直す。

| 対象 | 書き方 | 備考 |
|---|---|---|
| ベクトル | `\vect{E}` | 太字。手書きの矢印は使わない |
| 微分記号の d | `\dd`, `\dv{y}{x}`, `\pdv{f}{x}` | 立体(斜体にしない) |
| 誘電率 | `\eps_0` | `\varepsilon` |
| 勾配・発散・回転 | `\grad` `\divg` `\rot` | 演算子なので立体 |
| 単位 | `\unit{N/C}`, `\qty{9.8}{m/s^2}` | siunitx。数値と単位の間の空白は自動 |
| 式番号 | `\begin{equation}\label{eq:名前}` | 参照は `式~\eqref{eq:名前}` |
| 教科書への参照 | `\src{p.63}` | 転載の代わりに参照を残す |

## 囲み

| 環境 | 使い所 |
|---|---|
| `point` | 一番大事な一文 |
| `caution` | つまずきやすい所 |
| `question` | 確認問題 |
| `fact` | 定理・法則: `\begin{fact}{名前}` |
