---
description: 教科書の該当箇所から解説を書き、ビルドして、検査する。参考書づくりの1単元分。
---

単元の解説を **1つ** 作ってください。引数: $ARGUMENTS
(例: `2-6_分岐公式 young_em の p.63-66`)

CLAUDE.md の「守ること」を必ず守ります。

## 手順

1. **材料を集める**
   - `ocr/<本>/` から該当ページの Markdown を読む。無ければ、ユーザーに
     `uv run tools/local_read.py sources/<本>/ --book <本>` の実行を頼んで止まる
   - `[?]` の箇所と、図・式が多いページは、`sources/` の元画像を実際に見て確認する
   - `dict/` を検索して、既に書いた用語・定理・記号を把握する
2. **書く**: `template/unit.tex` から `notes/<単元名>/main.tex` を作り、CLAUDE.md の型で書く。
   図は `tools/crop.py` で切り抜いて `figures/` に置き、`\includegraphics{ファイル名}` で貼る
3. **ビルド**: `./build.sh notes/<単元名>`。失敗したらサブエージェント `tex-fixer` に、
   エラー表示と対象フォルダを渡して直させ、通るまで繰り返す(最大5回)
4. **検査**: サブエージェント `checker` に、単元名と参照元(ocr のファイル・元画像)を渡す。
   `誤り` と判定された箇所は直して、3 に戻る。`要確認` は最後の報告に残す
5. **辞書を更新**: 新しく出た用語・定理・記号を `dict/` に追記する
6. **報告**(6行以内): 作った PDF のパス / ビルドの結果 / checker の判定の内訳 /
   読めなかった箇所 / 教科書と食い違っていそうな箇所 / dict に足したもの
